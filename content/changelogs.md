Each FAST-HEP package keeps its own changelog in its repository. This page is a stopgap index until
the documentation sites are unified — for now, see each package's `CHANGELOG.md` directly on GitHub:

* [`fasthep`](https://github.com/FAST-HEP/fasthep/blob/main/CHANGELOG.md) — meta package
* [`fasthep-flow`](https://github.com/FAST-HEP/fasthep-flow/blob/main/CHANGELOG.md) — workflow compiler and runtime
* [`fasthep-carpenter`](https://github.com/FAST-HEP/fasthep-carpenter/blob/main/CHANGELOG.md) — HEP analysis transforms
* [`fasthep-curator`](https://github.com/FAST-HEP/fasthep-curator/blob/main/CHANGELOG.md) — dataset inspection and metadata
* [`fasthep-render`](https://github.com/FAST-HEP/fasthep-render/blob/main/CHANGELOG.md) — plotting and reports
* [`fasthep-cli`](https://github.com/FAST-HEP/fasthep-cli/blob/main/CHANGELOG.md) — command-line interface
* [`fasthep-toolbench`](https://github.com/FAST-HEP/fasthep-toolbench/blob/main/CHANGELOG.md) — shared utilities
* [`fasthep-distributed`](https://github.com/FAST-HEP/fasthep-distributed/blob/main/CHANGELOG.md) — distributed execution
* [`fasthep-workshop`](https://github.com/FAST-HEP/fasthep-workshop/blob/main/CHANGELOG.md) — examples and tutorials

`fasthep-distributed` is included here even though it does not yet have its own section on the
[Packages](/packages/) page — that page predates `distributed` joining the release set, and updating
it is a separate, larger content task outside this plan.
